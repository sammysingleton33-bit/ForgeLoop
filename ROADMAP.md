# Roadmap

Targets, not promises. Quality and functional completeness gate every milestone; gameplay milestones are accepted only by a user Studio playtest.

## Phase 0 — Factory bootstrap ✅ (2026-10-12)
Contract, team, task tooling, toolchain, dedicated repo, research and shortlist, worker prompts, shared skeleton (PR #1, CI green, awaiting FORGE-05 merge).

## Phase 1 — Game #1: AI Kingdoms (D-020)
- **VS-1 first playable (v2, D-030):** the user's nine items: a colourful kingdom; an aerial camera with the ruler on the throne; generated AI citizens working; the economy; building and upgrading on plots; barracks recruiting; a capture objective; an interactive HUD with six reputation values; and a citizen conversation decision with visible consequences (`games/game-001/BRIEF.md` §4). Accepted only by a user Studio playtest.
- **VS-2:** four dressed kingdoms, AI governors, raids, walls/gates, a simple siege, match timer with phases, and the **Crown Arena** final duel with citizen support (D-029, `games/game-001/design/crown-arena.md`), then the victory screen and leadership recap.
- **VS-3:** alliances/betrayal, trade, persistent progression, polish, mobile performance pass, release checklist → user approval → publish.

## Phase 2 — Live improvement and Game #2
Post-release analytics, lessons promoted to standards, prompt v2 (FL-0042), reusable systems extracted from game-001, faster Game #2.
